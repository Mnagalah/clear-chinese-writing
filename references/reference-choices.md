# 参考说明

下列摘记保留了本技能实际使用的资料要点，按写作问题组织，并标明来源、版本和核对位置。正文以转述为主，应用建议与原资料的结论分别说明。外链供追溯，链接失效不影响读取包内要点。

| 当前问题 | 包内摘记 | 查阅内容 |
|---|---|---|
| 语序、句段联系、连接成分、语气与词语 | [语言与篇章](source-notes/language.md) | 上下文怎样影响表达；语法、意义和语用层次怎样区别 |
| 句号、逗号、分号、冒号和小标题 | [标点与标题](source-notes/punctuation-and-headings.md) | 停顿与句意的关系，提示范围，段落和标题的对应 |
| 数字、单位、混排及技术文档 | [格式与技术说明](source-notes/formatting.md) | 常用排法、机构间的不同约定，以及使用条件 |

普通写作先使用入口与任务指南。只有需要澄清某个判断时，才读取对应摘记，不从参考目录开始逐项打开文件。引用原文、核查摘记未覆盖的精确条款，或判断现行版本时，才另查原件；无法取得时说明具体缺项，不把转述当成原文引用。

摘记收录的是标明版本的内容。后来更新的网页、标准或机构约定可能不同；涉及指定地区、期刊或产品时，遵守该任务已经给出的编辑要求。教学例子均为合成材料，与原资料的例句分开。
