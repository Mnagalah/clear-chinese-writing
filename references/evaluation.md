# 试写比较

评估写作技能，要看它面对新材料时写出了什么。格式、链接和文件完整性另行检查，不用它们证明语言自然。

先保存旧版，再选未出现在技能示例里的材料。材料应有需要取舍的内容，例如互不相同的意见、不能同时满足的需求、与直觉不符的数据，或本来已经写得不错的一段话。不要预先把结尾和观点写进材料，也不要故意编一篇满是套话的旧稿让新版去战胜。

旧版、新版使用相同的任务、篇幅要求和材料，由各自不知另一版输出的试写者完成。保存原始输出和实际加载的文件。比较前记录关注的问题：有没有改变事实或人物立场，关键解释是否保留，段落能否跟得上，是否习惯性补总结。允许某一题差别很小或旧版更好。

请未参与修改的人阅读匿名排列的两份稿，说明更愿意采用哪份，并引用具体句段解释。评阅者仍应看到原始材料，否则可能把补造细节误认成文笔。一次试写只能说明这几个任务的表现；模型评阅也不能代替读者反馈。

根据发现修订后，说明哪些原始输出属于修订前版本。检查明确缺陷可以重试；要检验能否用于别的材料，就另选一题。技能内的教学示例、开发时试写和后续实际使用分别记录，不把自己修改过的稿子冒充未经干预的结果。
